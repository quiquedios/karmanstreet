The source panel method

Theory · sources: thesis

The source panel method computes inviscid, incompressible flow around a body without meshing the whole domain. Only the surface is discretized, which makes it cheap enough to be a genuinely interactive design tool.

How it works

The surface is broken into N straight panels, each carrying an unknown source strength. The boundary condition — no flow through the surface — is enforced at a control point on each panel, which turns the problem into a linear system for the source strengths. Solving it gives the distribution, from which the surface velocity and the pressure coefficient follow everywhere.

Building that system requires the geometric influence coefficients: how much a unit source on panel j contributes to the normal velocity at panel i. In the implementation these came from analytical evaluation of the panel integrals rather than numerical quadrature, which keeps the accuracy high and the cost low.

Validation and convergence

Validating against theoretical expectations for a circular geometry confirmed physically consistent Cp distributions — the suction and pressure regions in the right places — with residuals of the order of 10⁻¹⁶, which is machine precision.

The more interesting part of the project was the convergence analysis: systematically increasing the panel count and watching the residual fall monotonically, which quantifies the trade-off between computational cost and numerical precision. Pushing further exposed the numerical artefacts that appear at very high panel counts — cancellation errors and discretisation limits — which is a useful reminder that more panels is not indefinitely better.
