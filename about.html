About

Hi — I'm Enrique. This site is where I explain aerodynamics in plain terms, write up the projects I'm working on, and keep a running portfolio.

The name is a nod to the von Kármán vortex street: the regular, alternating pattern of swirls that peels off a body in a flow. It felt like a fitting name for a place that's mostly about what air does.
